## 3. 用户旅程与关键场景

### 旅程 J-1：创建并跟踪一个虚拟任务（推荐基线）

1. 使用者进入虚拟任务管理界面；
2. 使用者创建一个新的虚拟任务，填写任务名称（必填）与可选描述；
3. 系统保存任务并将其列入虚拟任务列表，初始状态为"待处理"；
4. 使用者可选择将任务推进为"进行中"；
5. 使用者完成任务后将其标记为"已完成"；
6. 使用者可查看历史任务，或在不再需要时删除该任务。

关键决策点与系统反馈：

- 创建时名称为空：系统阻止保存并提示名称必填；
- 删除时：系统要求确认，删除成功后任务从列表消失。

### 场景 S-1：查看虚拟任务列表（推荐基线）

使用者打开任务列表，可以看到所有未删除的虚拟任务及其当前状态与创建时间。

## 4. 状态模型与业务规则（推荐基线）

### 状态定义

| 状态 | 含义 |
| --- | --- |
| 待处理 | 任务已创建，尚未开始 |
| 进行中 | 任务已被开始执行 |
| 已完成 | 任务已被完成 |

### 状态转换

- 待处理 → 进行中：使用者显式开始任务；
- 待处理 → 已完成：使用者直接完成任务（允许跳过"进行中"）；
- 进行中 → 已完成：使用者完成任务；
- 进行中 → 待处理：使用者将任务退回待处理；
- 任意状态 → 已删除：使用者删除任务。删除为移除而非状态：被删除任务不再出现在列表中，且不可恢复（推荐基线：无回收站/软删除）。

### 通用约束

- 状态转换只能由使用者的显式动作触发；
- 已完成任务不可再转换为其他状态（推荐基线）；
- 系统不得出现状态模型之外的状态值。

## 5. 分模块功能需求

### 模块 M-1：虚拟任务管理（推荐基线）

**FR-01 创建虚拟任务**

- 行为：使用者提交任务名称（必填、非空白）与可选描述，系统创建任务；
- 业务规则：名称去除首尾空白后不得为空；同一列表内允许同名任务，不强制唯一性；
- 边界与异常：名称为空或仅含空白时，系统拒绝创建并给出可理解的提示；
- 禁止结果：未成功保存的任务不得显示为已创建。

**FR-02 查看虚拟任务列表**

- 行为：使用者可查看全部未删除任务，含名称、状态与创建时间；
- 引用：场景 S-1。

**FR-03 更新任务状态**

- 行为：使用者按第 4 节状态转换规则推进或回退任务状态；
- 边界与异常：尝试非法转换（如"已完成"→"进行中"）时，系统拒绝操作并保持原状态；
- 禁止结果：不得出现状态模型之外的状态值。

**FR-04 删除虚拟任务**

- 行为：使用者可删除任意状态的任务，删除需确认；
- 业务规则：删除后任务从列表消失且不可恢复（见第 4 节删除规则）；
- 异常：删除确认被取消时，任务保持不变。

**FR-05 编辑任务内容（推荐基线，低优先级）**

- 行为：使用者可修改任务名称与描述；
- 业务规则：修改名称时同样受非空校验约束。
